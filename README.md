# Velocity Reporting

Executive dashboards for tracking Developer Velocity Work. Includes program of work across Developer Experience (DX) and AI Adoption.

## Dashboards

- **dx-executive-dashboard.html** — Weekly DX/Dev Tool Efficacy dashboard tracking AI maturity, CI performance, PR review experience, continuous delivery, and AI migrations.

## Usage

Open the HTML files directly in a browser:

```bash
open dx-executive-dashboard.html
```

## Structure

Each dashboard section includes:
- Platform OKRs with DRI ownership
- Primary metrics with status indicators (green/yellow)
- Collapsible status updates
- Collapsible secondary/load metrics
